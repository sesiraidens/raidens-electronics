## Sobre

Documentacao de circuitos eletricos: alimentacao, protecao, distribuicao de energia, sensores, motores e comunicacao. Diagramas em ASCII art.

---

## Circuitos

| Categoria | Conteudo |
|---|---|
| power/ | Fontes 5V, dual, conectores |
| protection/ | Polaridade, fusivel, crowbar |
| distribution/ | Distribuicao de energia, barramento GND |
| sensors/ | Barramento I2C, SPI, MUX analogico |
| motors/ | L298N, servo driver, ESC |
| communication/ | Serial, level shifter, Bluetooth |
